FoxThinking #39: 需要看情况吗？

by SouthFox2026-08-31

除了电车难题，还有很多奇奇怪怪的道德难题。

康德提出的：如果有朋友慌慌张张躲进你家里说有杀人狂追杀，随后一人问到他是否在你家里，那是否要如实回 答？康德说要如实回答。除了不能违背绝对命令外，康德还 说总不能排除一种情况，说谎让离开的杀人狂刚好碰上准备出逃的朋友。因为会有这种情况发生，所以不能说谎。

这个论证让人感到迷惑，从而开启了一轮又一轮的辩论。而我最近在看的书《周易大全》里就给了另一种看法 1 ：

有一天，李叔叔来找你。请问，你要不要见他？你心里马上盘算一下，他来找我干吗？然后一想，他八成是来打我的。怎么办？[...]

你叫孩子去告诉李叔叔自己不在家，客人走后，你一定要把孩子叫过来，问他：“我明明在家，为什么叫你去说我不在家？这是什么 意思？”然后一定要告诉他原因，不然他会一辈子受害。孩子会有一个答案，很有趣，他会说：“你骗人。” 你说：“我怎么会骗人？你从小到大，我都教你不能骗人，怎么我自己反而在骗人？” 孩子依旧会讲一句很有趣的话：“小孩子不可以骗人，大人可以。” 你说：“根本不是这样。小孩子不可以，大人更不可以！”我们整天学辩证法，却不会用在生活上。

孩子问：“那你为什么要这样做？” 你可以趁机教育他：“平常李叔叔见我，我都很高兴，但这一次我猜测他是来打我的。那我是出去被他打，还是躲起来比较好？当 然要躲起来了，可是我自己出去告诉他我要躲起来，我躲得掉吗？” 孩子说：“那当然躲不掉。” 你说：“那怎么办？只有你出去告诉他，我不在家。那这样算不算骗人？”孩子会说：“不算骗人。” 你说：“明明是骗人，怎么不算骗人呢？” 这样讲完，孩子的思维就打开了，他会讲一句非常有智慧的话：“爸爸，这个不能怪你，这完全是李叔叔做人太不像话。人家 明明在家，都不愿意跟他见面，他要检讨他自己，跟你有什么关系？” 你可以鼓励他：“你很了不起，终于把这条线搞懂了。”

这段话确实说出了我对于这个康德回应的迷惑：一、对面不仁为什么还要怪我不义？二、生命价值对于这个场景的盈满不值一 提，还遵守什么绝对命令就太死板了。生活实践中没有什么能「无脑」根据模板能一直通约的决策，一定 都是根据普遍的准则根据所面对的人或事作出行动——所谓的「见人说人话，见鬼说鬼话」。想为道德伦理建立绝对顺序是行不通的，有点像道德伦理上的是阿罗不可 能定理 2 ，就算生命价值、诚实、个人自由这三种道德准则，也无法排序出普遍性的群体排序。所以，还能怎么办呢？如果做不到不顾其它因素一往直 前，那能做的就是「看情况」了吧。

阅读

《周易大全》

作者明显是受到正规训练的哲学大家，从上面明显在揶揄康德例子的文字就能窥见一二。可里头也有很多「老登味发言」，这就让我觉得这本书 还真是有点令人琢磨不透，带了点「暧昧」的距离？作者真是这么想的？还是意识到书的面向群体所以有点曲折的方式行教化之举？还 是挺让人好奇的。毕竟《周易》可以说是中华文化最熟悉的陌生书籍了，日用而不知。甚至连靠这个吃饭的都懵懵懂懂：一两年前有个挂着什么挂 着医师名号晃过行政来公司开会，在讲了点什么现代生活久坐、饮食的危害什么的就马上开始兜售体检套餐了。或许是有着多年的演讲经验吧，唬得 人一愣一愣的，但在拿「三阳开泰」举例的时候，在白板画卦将地天泰的卦画反反了互综的卦天地否！这可就整个垮掉了， 泰卦讲究的是天下地上，阴阳交感，所以讲究三阳「开」泰；上天地下的否卦则是有口不能言，闭塞不通，其中的三阳都是警醒之意。意思完全相反，真 是令人哭笑不得 3 ，除了让人感叹草台外，还有就是怎么连做到吃这碗饭的都这么「不专业」啊。

AI 编程时代，被誉为「软件工程圣经」的《人月神话》，有哪些理论过时了？ - 知乎日报

初读《人月神话》只能找出四五条观点，同时还觉得这本书写得很通俗外好像就没什么了，直到现在有了实际项目经验后，就能找出十多条观点了。 不愧是能经受几十年时间检验的书，应该还能继续「撑」过下一个几十年。

An Introduction to Canvas in GNU Emacs

Emacs 的 canvas patch 终于合并到主线了，意味着下一个大版本后有很多有趣的图形包或库会涌现出来。其中最实用的就是 阅读器包 emacs-reader 了，对比 pdf-tools 能以更高效率查看文件并增加更多文件格式支持。甚至如果到时我还有余力的话，或许还能搭 配 orgmode 笔记写点着色器把玩下计算机图形学。

For the First Time, a Cell Built From Scratch Grows and Divides | Quanta Magazine

生物学家首次将非生物成分融进类细胞膜结构中并表现出了分裂的生命活动，虽然这只是阶段性的成果，但不由得畅想这个如果推广开来将是一次工具上的进化。任 何实验室都能自行组装对应的人造细胞来搭配实验，就像……开发板一样。或许几十年后任何爱好者都能在自己家中通过类似的人造细胞搭配点工程语言设计并构建出 什么材料来，虽然大概率这种工程语言也是中缀表达式语言，但我完全不意外会有什么 Lisp 绑定方言冒出来，毕竟 Lisp 拒绝消亡！

一呼百应

《Wild Blue Skies》

各种意义上都很迷惑的游戏，还在找街机时代的魂，弄出什么命数制（甚至不能续关）然后还搞多种初见杀。搭配上分支选择和不长的流程明显是让人背板 游玩，但就算是这样，隔壁的也有着街机之魂的 《Sayonara Wild Hearts》也有着快速重试无限续关并把一命通关放在挑战模式这种不 让人心生暴躁的设计，真不相信游戏制作组是真没考察过类似的街机游戏设计吗？

甚至在最终 Boss 关还遇到了软锁定 4 无法推进，不由得想问这游戏上线前做了质量管控吗？不过看在小厂出品的份上就不差评了，等个一年半载 的游戏更了几次补丁后在看看吧。

《Hades II》

不停刷着很多时候就有种无言的「绝望」，可能是随着越玩越多就对各种数据曲线有所感应吧，以及轻肉鸽的设计导致变化实在不大，感到现在的伤害乏力就知 道这把完了，不如重开来 roll 个 like 。或许我会和一代一样，在玩完大部分可玩内容后，就将所有挑战点满突破下最高难度后就封盘。

《Minecraft》

起因是月中看到了机械动力的宣传片（ Create Aeronautics Mod Release Trailer - YouTube ）然后转发到 小群大家一起感叹，然后月末就开始估量着趁着在暑假结束前 （虽然群里大家都不是学生了）再开一次 Mineraft ，所谓的 Minecraft 之痒：没来由的就突然 很想玩，或许玩不了几天但就是……很想玩。发现我对 Minecraft 的印象还停留在 1.12 上，也没玩过之后大热的如机械动力的模组，那么是时候了，该鼓捣鼓 捣了（虽然现在看来大部分都是在折腾计算机模组的 lua 绑定上，想着写点代码来做产线管理或飞行器转向控制啥的。

Present day, Present time

马上就是 8.32 了，又是一年（北半球）的夏天要过去了啊。
